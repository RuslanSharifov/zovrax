# ZOVRAX Hub

Manage official ZOVRAX Minecraft mods from a single, rebindable key: **Right Shift**.

## One place for ZOVRAX

- **My Mods:** See official ZOVRAX mods actually installed in your Minecraft client. Select a mod to open its original settings and return to Hub. Gameplay shortcuts remain intact.
- **Explore:** Discover mods on the official ZOVRAX site from inside Minecraft. Search by name or description, filter by category, and sort by latest update or name.
- **Version-aware downloads:** Hub checks a mod's real releases before enabling the Fabric 1.21.10 download action. Confirm before opening the official download in your browser.
- **Offline cache:** Previously fetched information remains available when the website is offline.

The interface uses native Minecraft controls with translucent dark-glass styling. Initial-letter tiles are used in the first release; remote SVG thumbnails are not yet rendered inside Minecraft.

## Compatibility

Minecraft Java **1.21.10** • **Fabric** • **Java 21** • client-side. Fabric API required. Hub and the other ZOVRAX mods are independent.

Real release availability follows successful build verification and publication. Source and build details appear in the repository README.
