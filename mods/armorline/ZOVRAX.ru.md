# ArmorLine

**Бета 0.2.0 · Minecraft Java 1.21.10 · Fabric**

ArmorLine отображает шлем, нагрудник, поножи и ботинки в **одном вертикальном связанном HUD**. При смене экипировки иконки обновляются, пустые слоты остаются пустыми. Можно выбрать и горизонтальное расположение.

Нажмите **P** для настроек. Выбирайте вид прочности: **полоса и числа**, только полоса, только оставшаяся/максимальная прочность или полностью скрыть. Показатели можно расположить **автоматически, слева, справа или скрыть**.

Прозрачность **всего HUD, фона, иконок брони и текста/полос** задаётся отдельно (0–100%). Фон можно сделать полностью прозрачным. Размер — 50–200%.

В редакторе **Customize HUD position** перетаскивайте весь блок мышью, нажмите на него, чтобы изменить расположение и прозрачность. Версия 0.2.0 исправляет проблему, при которой нажатие кнопки могло ошибочно перемещать HUD, а изменения после Done иногда не применялись. Настройки сохраняются, старые настройки 0.1.0 переносимы.

Minecraft 1.21.10, Fabric API, Java 21. Удалите предыдущую версию ArmorLine перед установкой новой 0.2.0. Автоматическая компиляция выполнена, тесты в игре ещё необходимы.


## Новое в бете 0.3.0

Интерфейс теперь повторяет пример: **четыре иконки брони вертикально**, белые числа оставшейся прочности слева. **Инструмент в основной руке** показывается справа, а **щит, тотем бессмертия или другой предмет во второй руке** — ниже, если слот не пуст. Предметы без прочности не получают фиктивные числа.

В настройках по **P** можно независимо отключать отображение основной и второй руки. Для новых настроек фон полностью прозрачный (0 %). Старые настройки сохраняются; прозрачность фона можно вручную выставить на 0 %. Другие параметры HUD остаются доступны.
