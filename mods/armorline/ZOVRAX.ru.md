# ArmorLine

**Minecraft Java 1.21.10 · Fabric · Бета 0.1.0**

ArmorLine показывает шлем, нагрудник, поножи и ботинки в одном связанном HUD. Пустые ячейки остаются пустыми. При смене брони отображение сразу обновляется.

Выберите **вертикальное или горизонтальное** расположение всех четырёх элементов. Для каждой части брони можно включать и выключать полоску прочности и точные значения **оставшаяся / максимальная прочность**.

Нажмите **P**, чтобы открыть настройки. В них доступны включение/выключение HUD, размер 50–200%, прозрачность 0–100%, формат и индикаторы прочности. Нажмите **Customize HUD position**, чтобы перетащить весь блок мышью. Нажмите на блок — появится панель настройки размера, прозрачности и направления.

Клиентский мод для **Fabric 1.21.10**, требует Fabric API и Java 21. Настройки независимы от Inventory Pickup. Бета JAR собран автоматически; проверка в игре ещё необходима.
