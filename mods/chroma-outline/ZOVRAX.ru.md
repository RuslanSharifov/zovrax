# Chroma Outline

Измените обычную обводку блока, на который вы смотрите.

- Радужная анимация со скоростью, насыщенностью и яркостью.
- Однотонный цвет с настройкой RGB и прозрачности.
- Эффект пульсации, приблизительная толщина линий, расширение формы.
- Контур по форме блока или по полному кубу, готовые профили.

Нажмите **O** в игре для настроек. Конфигурация сохраняется автоматически.
Требуются **Minecraft Java 1.21.10**, **Fabric**, **Java 21** и **Fabric API**.
Толщина создаётся дополнительными линиями, а не точной шириной в пикселях.
