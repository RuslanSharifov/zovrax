# SmartReturn 1.0.0 — Retrouvez la sortie de vos grottes Minecraft

Mod client gratuit pour **Minecraft Java 1.21.10 / Fabric / Java 21 / Fabric API**. Le trajet est mémorisé automatiquement ; le guidage ne s'active que sur demande.

- **R** pour afficher ou masquer les directions et **K** pour les réglages.
- Jusqu'à huit grottes indépendantes par monde et dimension. Plusieurs sorties connues : l'itinéraire le plus court utilise les chemins réellement parcourus.
- Une flèche vectorielle fluide, avec réglage de la position X/Y, de la taille et de l'opacité.
- Dix pistes animées : empreintes, pointillés, ligne pleine, points, chevrons, balises, runes, scintillements, rubans et cubes flottants.
- Fonctionne en première et troisième personne. Le mode « derrière les murs » projette les repères sur l'écran.
- Interface automatiquement traduite en anglais, français, russe, turc et chinois simplifié. L'anglais reste la langue par défaut.
- Compatibilité avec les trajets sauvegardés par la version 0.1.0 ; rappel discret facultatif.

**Version bêta :** la reconnaissance des grottes reste approximative. Compilation et tests de calcul validés ; essais en jeu encore nécessaires.
