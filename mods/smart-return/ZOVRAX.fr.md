# SmartReturn

Petit mod client gratuit pour Minecraft Java 1.21.10, Fabric et Java 21 (Fabric API requis). Il mémorise discrètement le trajet parcouru dans une grotte.

Le mod essaie de repérer l'entrée et peut afficher **un seul rappel facultatif** après trois minutes. Le guidage ne démarre **jamais automatiquement** : appuyez sur **R** pour l'activer, et sur **K** pour les réglages.

Choisissez les **flèches 3D**, la **mini-boussole**, ou **les deux**. Les boucles sont réduites uniquement sur les chemins réellement parcourus ; aucune traversée magique des murs.

Le dernier trajet de chaque monde et dimension est conservé après redémarrage. La détection des grottes n'est pas parfaite et les passages modifiés peuvent rendre l'itinéraire inutilisable.

Compilation et métadonnées du JAR vérifiées lors de la publication ; les tests en jeu restent nécessaires.
