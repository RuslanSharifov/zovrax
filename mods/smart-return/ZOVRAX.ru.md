# SmartReturn

Бесплатный клиентский мод для Minecraft Java 1.21.10 (Fabric, Java 21, Fabric API), который незаметно запоминает маршрут по пещере.

Мод пытается определить вход, записывает пройденные коридоры и может один раз напомнить о записи через три минуты. **Навигация включается только вручную по клавише R.** Настройки — клавиша **K**.

Режимы навигации: **3D-стрелки**, **мини-компас** или **оба одновременно**. Петли сокращаются только по реально пройденным связным маршрутам; через стены мод не прокладывает путь.

Путь сохраняется по миру и измерению и доступен после перезапуска. Сохраняется один последний маршрут для каждой пары мир/измерение.

**Ограничения:** обнаружение пещер приблизительное; закрытые или изменённые коридоры могут помешать возвращению. Сборка JAR проверяется автоматически, но полноценное тестирование в самой игре ещё требуется.
