# SmartReturn 1.0.0 — Возвращение из пещер Minecraft

Клиентский мод для **Minecraft Java 1.21.10 / Fabric / Java 21 / Fabric API**. Путь запоминается автоматически, но навигация включается только вручную.

- **R** — показать или скрыть маршрут; **K** — настройки.
- До восьми независимых пещер на мир и измерение, с учётом нескольких реальных входов. Кратчайший путь строится только по ранее пройденным коридорам.
- Плавно вращающаяся графическая стрелка компаса: настройте положение X/Y, размер и прозрачность.
- Десять анимированных видов следа: отпечатки ног, пунктир, сплошная линия, точки, стрелки, маяки, руны, искры, две ленты и парящие кубы.
- Работа от первого или третьего лица. Режим сквозь стены показывает проецируемые точки на экране.
- Автоматически выбираются английский, французский, русский, турецкий и упрощённый китайский языки; по умолчанию английский.
- Поддерживается загрузка старых маршрутов версии 0.1.0. Напоминание через несколько минут необязательно.

**Бета-версия:** определение пещер приблизительное. Сборка и тесты графа проверены; игровое тестирование ещё необходимо.
