# HarvestPulse

Бесплатный мод для Minecraft Java 1.21.10 / Fabric, который показывает готовность урожая по выбранным участкам.

Нажмите **H**, выделите два противоположных угла поля правой кнопкой мыши, задайте имя и выберите отображение: всегда, только при 100%, либо скрыть. Для каждого поля доступна полоса прогресса, процент и количество собранного к уборке урожая. При полной готовности отображается колокольчик. Поля можно переименовывать, менять порядок, удалять, а HUD — перетаскивать.

Мод работает **на стороне сервера и клиента**. Сервер обрабатывает выбранные культуры, даже когда игрок далеко, с ограничениями: до 8 полей на игрока, максимум 16 × 16 блоков каждое. Поддержаны пшеница, морковь, картофель, свёкла, адский нарост, какао и сладкие ягоды. Нужны Minecraft 1.21.10, Fabric API и Java 21. На сервере мод тоже обязателен. Не работает, когда сервер остановлен или игрок вышел из игры. Стадии роста проверяются по фактическому состоянию блоков.

**Бета 0.1.0:** компиляция и структура JAR проверены; тесты внутри Minecraft ещё необходимы. MIT, только бесплатно.
