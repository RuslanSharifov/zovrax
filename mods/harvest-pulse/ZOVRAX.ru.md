# HarvestPulse 0.2.0 — умный индикатор урожая

**Бесплатная бета для Minecraft 1.21.10 / Fabric.** Нажмите **H**, выберите предел 16/32/64/128 блоков и укажите два угла поля. Полупрозрачный **зелёный** цвет означает допустимую область, **красный** — слишком большую или пересекающуюся с сохранённым полем, **голубой** — уже зарегистрированную ферму. В меню по H можно отменить выделение.

Для каждого поля доступны название, порядок, процент/количество, режим постоянного отображения или появления только при 100 %. В момент полной зрелости появляются **колокольчик**, анимированное появление, по желанию звук и уведомление Minecraft справа вверху. Перетаскивайте HUD мышью, кликайте по нему для настройки размера и прозрачности.

На сервере работает ограниченная по нагрузке обработка далёких посевов и полная периодическая проверка реальных блоков. Для больших полей обновления могут быть редкими; сервер не гарантирует точно такую же частоту роста, как ванильная игра. **Для мультиплеера установите мод на сервер и клиент.** Beta 0.2.0 прошла компиляцию, но требует проверки внутри игры.
