# HarvestPulse — монитор полей

**Бесплатная бета 0.2.0 · Minecraft Java 1.21.10 · Fabric**

Выберите максимальный размер 16×16, 32×32, 64×64 или 128×128 блоков. Кликните два угла поля. Прозрачная разметка у поверхности земли: **зелёная** — допустимое выделение, **красная** — недопустимое, **голубая** — уже зарегистрированное поле. Откройте H, чтобы отменить выбор.

Несколько именованных полей с процентами созревания и полосой прогресса. При реальных **100%** на полосе появляется колокольчик; сдвиг, плавное появление, необязательное уведомление вверху справа и звук. В редакторе HUD нажмите для изменения размера и прозрачности либо удерживайте/дважды щёлкните и перетащите для перемещения.

Для роста вдали от игрока мод необходим и на **сервере**, и на клиенте. Удалённая обработка ограничена по нагрузке; большие поля проверяются по частям. Живая проверка игрового процесса ещё требуется.
