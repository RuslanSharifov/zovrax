# Extended Reach

**Cassez et placez des blocs jusqu'à 16 blocs de distance dans Minecraft Java 1.21.10 (Fabric).**

Ouvrez les options avec la touche **O** (personnalisable) ou avec le bouton **Configurer** de Mod Menu, si installé. Réglez la portée **de 5 à 16 blocs**, avec **8 blocs** par défaut. Le choix est enregistré automatiquement.

En solo, le mod fonctionne avec le serveur intégré. En multijoueur, il doit être installé **sur le client et sur le serveur** : le serveur valide chaque distance demandée et la limite à 16 blocs. Un client seul ne peut pas contourner les restrictions d'un serveur non modifié.

Minecraft **1.21.10**, Fabric Loader **0.17.3+**, Fabric API et Java **21** requis. Mod Menu facultatif. Bêta gratuite **0.1.0** ; tests en jeu recommandés.
