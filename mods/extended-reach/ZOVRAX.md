# Extended Reach

**Break and place blocks from farther away — up to 16 blocks — in Minecraft Java 1.21.10 (Fabric).**

Extended Reach lets you choose how far away you can interact with blocks, without changing combat reach or how quickly blocks are mined. Build high walls, work around awkward corners and remove distant blocks without constantly walking toward them.

## Adjustable reach

Open **Extended Reach Settings** with **O** (rebindable), or choose **Configure** in Mod Menu when installed. The slider offers **5 through 16 blocks**, with **8 blocks** selected by default. Your preference is saved automatically for your next session.

## Multiplayer support

In singleplayer the mod works on both sides of your integrated game. On a multiplayer server, **the mod must be installed on the server as well as your client** so the server can allow the longer interaction range. The server verifies every requested value and never accepts a requested distance greater than 16 blocks. On vanilla servers your selected distance cannot override the server's restrictions.

## Requirements

- Minecraft Java **1.21.10**
- **Fabric Loader 0.17.3+**
- **Fabric API 0.138.4+1.21.10**
- **Java 21**
- **Mod Menu 16.0.1** (optional, for the Configure button)
