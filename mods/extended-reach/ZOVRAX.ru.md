# Extended Reach

**Разрушайте и размещайте блоки на расстоянии до 16 блоков в Minecraft Java 1.21.10 (Fabric).**

Используйте клавишу **O** (её можно переназначить) или кнопку **Настроить** в дополнительном моде Mod Menu. В настройках доступна дистанция **от 5 до 16 блоков**, по умолчанию **8**. Значение сохраняется автоматически.

Для одиночной игры достаточно установить мод в клиент. Для сетевой игры **мод требуется и на клиенте, и на сервере**: сервер проверяет выбранное расстояние и ограничивает его 16 блоками. Установка только на клиент не отменяет ограничения обычных серверов.

Требуется Minecraft **1.21.10**, Fabric Loader **0.17.3+**, Fabric API и Java **21**. Mod Menu необязателен. Бесплатная бета **0.1.0**; полноценное тестирование в игре ещё рекомендуется.
