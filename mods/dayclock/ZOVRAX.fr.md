# DayClock HUD

Petit HUD gratuit pour **Minecraft Java 1.21.10 / Fabric**. Par défaut, il affiche le **jour du monde** et l'**heure de Minecraft**. Le soleil devient un croissant de lune quand le sommeil est permis par l'heure et la dimension. Cela ne garantit pas qu'un lit est libre ou qu'aucun monstre ne se trouve à proximité.

Appuyez sur **K** pour afficher au choix les coordonnées XYZ, le biome, la dimension, la direction, la météo et le niveau de lumière. Une deuxième page permet de régler l'échelle, l'opacité et la position du HUD en le faisant glisser. Paramètres dans `config/zovrax-dayclock.json`.

**0.1.0 beta** nécessite Minecraft 1.21.10, Fabric Loader 0.17.3+, Fabric API et Java 21. La compilation automatique ne remplace pas un test en jeu.
