# DayClock HUD

Бесплатный минималистичный HUD для **Minecraft Java 1.21.10 / Fabric**. По умолчанию показывает **день мира** и **внутриигровое время**. Солнце сменяется полумесяцем, когда по правилам игры наступает время сна; индикатор учитывает измерения, в которых кровати не работают. Доступность свободной кровати и отсутствие монстров рядом он не гарантирует.

Нажмите **K**, чтобы включить или выключить координаты XYZ, биом, измерение, направление, погоду и освещённость. На второй странице измените размер, прозрачность и положение HUD перетаскиванием. Настройки сохраняются в `config/zovrax-dayclock.json`.

Для версии **0.1.0** требуются Minecraft 1.21.10, Fabric Loader 0.17.3+, Fabric API и Java 21. Это бесплатная бета-версия; автоматические проверки сборки не заменяют проверку непосредственно в игре.
