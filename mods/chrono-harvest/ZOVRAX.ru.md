# ChronoHarvest

ChronoHarvest учитывает время с момента посадки, даже если чанк с урожаем был выгружен.

- Временные метки посадки сохраняются; рост пересчитывается при загрузке чанка.
- Обычный сбор зрелого урожая оставляет растение на стадии 0.
- Удерживайте Shift, чтобы полностью удалить растение; Shift также требуется для сбора незрелых культур.
- Настройки доступны через Mod Menu или клавишу K.
- Длительность стадии и поведение сбора настраиваются.

Minecraft Java 1.21.10 · Fabric · Java 21. Для мультиплеера установите мод на сервер и клиент.
