# ChronoHarvest

ChronoHarvest fait progresser les cultures selon le temps écoulé depuis leur plantation, même lorsque leur chunk est déchargé.

- Les dates de plantation sont enregistrées et la croissance est recalculée au chargement du chunk.
- Une récolte normale d'une culture mûre laisse la plante au stade 0.
- Maintenez Shift pour déraciner complètement la plante ; Shift est également requis pour récolter une culture immature.
- Ouvrez les réglages via Mod Menu ou avec la touche K.
- Réglez la durée de chaque stade et le comportement de récolte.

Minecraft Java 1.21.10 · Fabric · Java 21. Mod Menu est facultatif.
