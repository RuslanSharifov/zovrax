# Smooth Doors — плавное открытие дверей

Плавная анимация открывания **и закрывания** обычных дверей (включая створки двойных дверей) и люков. Отдельно регулируйте длительность открытия и закрытия от 100 до 2000 мс, включайте и выключайте анимацию или отдельные типы блоков. Меню настроек: **J**.

Клиентский мод для Minecraft Java **1.21.10**, Fabric, Fabric API и Java 21. Физика, редстоун и логика сервера остаются без изменений. Две соседние двери не связываются автоматически. Совместимость с шейдерами нужно проверить в игре.

### Версия 0.1.1 Beta

Исправлено наложение второй, слишком яркой двери поверх оригинальной: движущаяся модель отображается только после обновления меша исходной двери. После завершения анимации исходная дверь возвращается без визуального пропадания. Освещение соответствует миру Minecraft. Для Sodium, Iris и мобильных рендереров нужна проверка в самой игре.
