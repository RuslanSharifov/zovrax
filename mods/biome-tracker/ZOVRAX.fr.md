# Biome Tracker

Sachez où vous êtes, repérez les changements de biome et conservez l'historique de vos explorations.

Biome Tracker ajoute un HUD configurable affichant le biome actuel. Lorsque vous entrez dans un autre biome, Minecraft affiche une notification et peut jouer un son.

## Fonctionnalités

- **HUD personnalisable :** activation, position, taille et opacité.
- **Alertes de biome :** notification de titre Minecraft et son facultatif lors d'un changement.
- **Limites des biomes :** visualisation facultative des transitions proches avec des particules.
- **Statistiques de temps :** suivi du temps passé dans chaque biome, séparé par dimension et conservé entre les sessions.
- **Chronomètre actuel :** affiche facultativement la durée de la visite en cours sur le HUD.

## Commandes

Appuyez sur **B** pour ouvrir les paramètres. Configurez le HUD, les alertes, le son, les limites et le chronomètre. L'écran des statistiques affiche le temps cumulé dans les biomes.

## Configuration requise

- Minecraft Java Edition **1.21.10**
- Fabric Loader 0.17.3+
- Fabric API 0.136.0+1.21.10
- Java 21

Mod côté client ; aucune installation serveur n'est nécessaire.
