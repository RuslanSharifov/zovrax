# Biome Tracker

Узнавайте, где находитесь, замечайте смену биомов и сохраняйте статистику своих путешествий.

Biome Tracker добавляет настраиваемый HUD с названием текущего биома. При переходе в другой биом Minecraft показывает уведомление и, по желанию, воспроизводит звук.

## Возможности

- **Настраиваемый HUD:** включение и отключение, положение на экране, размер и прозрачность.
- **Уведомления:** заголовок Minecraft при входе в новый биом и необязательный звуковой сигнал.
- **Границы биомов:** ближайшие переходы можно подсвечивать частицами.
- **Статистика времени:** мод записывает время в каждом биоме отдельно для каждого измерения и сохраняет данные между игровыми сессиями.
- **Таймер посещения:** по желанию показывает время текущего пребывания в биоме на HUD.

## Управление

Нажмите **B**, чтобы открыть настройки. В меню можно настроить HUD, уведомления, звук, границы и таймер. Отдельный экран показывает накопленное время в биомах.

## Требования

- Minecraft Java Edition **1.21.10**
- Fabric Loader 0.17.3+
- Fabric API 0.136.0+1.21.10
- Java 21

Мод работает только на клиенте. Серверная установка не требуется.

## Статус релиза
