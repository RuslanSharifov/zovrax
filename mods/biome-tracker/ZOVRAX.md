# Biome Tracker

Know where you are, discover where the world changes, and keep a record of every journey.

Biome Tracker adds a compact, customizable biome HUD to Minecraft Java Edition. When you enter a different biome, the game displays a title notification and can play a short sound.

## Features

- **Customizable HUD:** turn it on or off, move it around the screen, and adjust its scale and opacity.
- **Biome change alerts:** receive a Minecraft title notification when you enter a new biome, with an optional sound.
- **Biome boundaries:** optionally reveal nearby biome transitions with subtle particles, similar in spirit to chunk-border visualization.
- **Playtime statistics:** automatically record time spent in each biome, separated by dimension, and preserve the totals between sessions.
- **Current visit timer:** optionally display how long you have been in the current biome directly on the HUD.

## Controls

Press **B** to open Biome Tracker settings. From there, customize the HUD, alerts, boundary markers and current-biome timer. Open the statistics screen to compare your accumulated biome playtime.

## Requirements

- Minecraft Java Edition **1.21.10**
- **Fabric Loader** 0.17.3+
- **Fabric API** 0.136.0+1.21.10
- Java 21

Client-side mod. The server does not need to install it.
