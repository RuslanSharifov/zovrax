# Inventory Pickup

> **В разработке — Minecraft Java 1.21.10, Fabric.** Исходники есть, проверенного JAR для скачивания пока нет.

Мод отображает получение предметов в инвентаре в виде плавных уведомлений HUD. Карточка выезжает и меняет прозрачность **0 → 100%**, показывает иконку, название, **+N** и общее число предметов. Затем уезжает с плавным исчезновением до 0%.

Регистрируются предметы, поднятые с земли или перенесённые из сундука. Перемещение между собственными слотами не вызывает ложных оповещений.

## Настройки в игре

Нажмите **O** (клавиша переназначается в Controls). Можно настроить угол экрана, продолжительность, скорость анимации, прозрачность, число уведомлений, поля и объединение повторов.

## Совместимость и загрузка

Minecraft Java **1.21.10**, Fabric и Fabric API. Клиентский мод, без изменения инвентаря и модификации сервера. Тестирование в игре и с другими модами ещё требуется; скачать JAR пока нельзя. [Исходный код](https://github.com/RuslanSharifov/zovrax/tree/main/mods/inventory-pickup).
