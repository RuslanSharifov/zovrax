# Inventory Pickup

> **Концепт · пока недоступен для скачивания.** Рабочий файл `.jar` ещё не опубликован.

Inventory Pickup — проект HUD-уведомлений для **Minecraft Java Edition 1.21.10 / Fabric**. При подборе предмета или переносе его из сундука мод будет показывать значок, название, общее количество в инвентаре и прибавку.

## Планируемые возможности

- Компактные уведомления о подборе предметов и прибавке `+N`
- Отслеживание перемещения из сундука в инвентарь
- Настройка положения, длительности и анимации
- Объединение повторных уведомлений

## Совместимость

| Minecraft | Загрузчик | Статус |
| --- | --- | --- |
| 1.21.10 | Fabric | Планируется |
