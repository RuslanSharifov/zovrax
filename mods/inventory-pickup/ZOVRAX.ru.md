# Inventory Pickup

> **Публичная бета 0.2.1 — Minecraft Java 1.21.10, Fabric.** JAR доступен для тестирования. Сборка прошла проверку, но эту версию ещё нужно испытать в самой игре.

Мод показывает плавные уведомления HUD только при **подборе предметов с земли и сфер опыта**. Уведомление выезжает, появляется и исчезает с анимацией прозрачности.

Если подобрать тот же предмет, пока его уведомление видно, счётчик **+N** обновляется в существующей карточке, а таймер отображения **сбрасывается**. Аналогично объединяются уведомления **+N XP**.

Перемещение предметов по слотам, уменьшение прочности инструментов, крафт и перенос вещей из сундука больше не считаются подбором с земли. Значение XP соответствует подобранной сфере; зачарование «Починка» может потратить часть опыта.

## Настройки

Нажмите **O**. Ползунки позволяют настроить длительность, анимацию, прозрачность фона с шагом 1% и количество уведомлений. В редакторе расположения карточку можно перетащить мышью, а по щелчку настроить её размер и прозрачность. Настройки сохраняются.

## Установка

Minecraft **1.21.10**, **Fabric Loader**, **Fabric API**, **Java 21**. Скачайте бета-версию **0.2.1** на вкладке **Downloads**. Удалите старый JAR Inventory Pickup из `mods` перед установкой. Версии 0.2.0 и 0.1.0 остаются доступными. Совместимость с другими модами следует проверить в игре.
