# Inventory Pickup

> **Публичная бета 0.1.0 — Minecraft Java 1.21.10, Fabric.** JAR доступен для тестирования. Сборка прошла успешно, но проверка непосредственно в Minecraft и с другими модами ещё не проводилась.

Мод отображает получение предметов в инвентаре в виде плавных уведомлений HUD. Карточка выезжает и меняет прозрачность **0 → 100%**, показывает иконку, название, **+N** и общее число предметов. Затем уезжает с плавным исчезновением до 0%.

Регистрируются предметы, поднятые с земли или перенесённые из сундука. Перемещение между собственными слотами не вызывает ложных оповещений.

## Настройки в игре

Нажмите **O** (клавиша переназначается в Controls). Можно настроить угол экрана, продолжительность, скорость анимации, прозрачность, число уведомлений, поля и объединение повторов.

## Совместимость и загрузка

Minecraft Java **1.21.10**, Fabric и Fabric API. Клиентский мод, без изменения инвентаря и модификации сервера. Бета-версию **0.1.0** можно скачать во вкладке **Downloads** (Minecraft 1.21.10 → Fabric → 0.1.0). Установите соответствующие Fabric Loader и Fabric API, скопируйте JAR в папку `mods`. Нужна Java 21. Это тестовый релиз, совместимость с другими модами пока не гарантируется. [Исходный код](https://github.com/RuslanSharifov/zovrax/tree/main/mods/inventory-pickup).
