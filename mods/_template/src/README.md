# Java source folder placeholder

There is deliberately no fake Java implementation in this template. A real Fabric, Forge, NeoForge or Quilt mod needs the **correct loader-specific project structure, Gradle build files, Java source, resource files and mod metadata** for its target Minecraft version. Use the official starter project for the loader and copy its source/build files into the mod folder.

Do not claim Minecraft/loader compatibility from a copied manifest. Build and test the actual mod before publishing a JAR.
