# New mod starter

Create mods/<unique-mod-id>/ with a real Java project and README.

Document target Minecraft Java Edition version, Fabric/NeoForge version, Java runtime requirements, installation and build instructions, license, authors, supported features and testing. Keep releases empty in site/data/mods.json until real tested .jar builds are published.

Follow CONTRIBUTING.md and AGENTS.md at repo root. Every new mod must be submitted by Pull Request for maintainer approval.
